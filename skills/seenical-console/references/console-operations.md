# Seenical Console 操作参考

| 功能区 | 核心操作 | 关键约束 |
|---|---|---|
| 构建 | Agent、会话、会话配置、LOOP、预览 | 主会话始终保留；一个 LOOP 对应一个执行子会话 |
| 知识库 | 创建、配置、上传、网站索引、挂载 Agent | 知识库可跨会话；会话上传资料仅限当前会话 |
| 内容 | 按 Agent 查看批次、预览、下载 | 列表分页，不把 LOOP 配置放入内容页 |
| 站点 | 切换、统计、托管、域名、SEO/分析设置 | 预览地址与正式地址不同 |
| 部署 | 查看批次并部署 | 发布和部署前确认目标站点 |
| 技能 | 查看公共技能、下载 Runtime 包 | 公共技能以 GitHub 同步版本为准 |
| 产品设置 | APP 与底层服务 | 一个 Seenical 产品对应一个 APP |
| 订阅 | 智能消息、知识库、托管、SEO、域名 | 以页面显示的当前套餐和余量为准 |
| 帐号中心 | 帐号认证、Token 管理 | Token 明文通常只在创建时显示一次 |
